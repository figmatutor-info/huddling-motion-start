# make-video

영상 한 편을 처음부터 끝까지 진행한다. 결과는 모두 `out/<영상이름>/`에 둔다. 기준은 CLAUDE.md와 `docs/`.

## 1. BRIEF (사람에게 세 가지만 묻기)
1. 무엇을: 어떤 화면 · 기능 · 메시지인가 (`docs/design.md` 6장 화면 목록에서 고르게 돕는다)
2. 몇 초
3. 레퍼런스: 링크 · 파일 (여러 개 가능. 없으면 "없음")

영상이름(짧은 영어, 예: `mission-approved`)을 정하고 `out/<영상이름>/BRIEF.md`에 적는다.

## 2. 레퍼런스 정리: `art-director`
→ `out/<영상이름>/reference.md` (체크리스트 · 새 후보)

## 3. 장면표: `director`
1. 3안 요약을 받아 사람에게 보여 준다.
2. **승인 1: 사람이 3안 중 하나를 고른다.**
3. 고른 안으로 장면표를 펼친다 → `out/<영상이름>/scenes.md`

## 4. 스냅보드: `builder` → `critic`
1. builder가 스냅보드를 만든다 → `out/<영상이름>/snapboard/`
2. critic이 판정한다. 탈락이면 builder가 걸린 곳만 고치고 다시 판정한다.
3. 통과하면 스냅보드를 보여 준다. **승인 2: 사람이 스냅보드를 승인한다.**

## 5. 영상: `builder` → `critic`
1. builder가 영상을 만든다 → `out/<영상이름>/<영상이름>.mp4`
2. critic이 판정한다. 탈락이면 4단계 2와 같이 고친다.
3. 통과하면 영상과 판정 한 줄을 보여 주고 끝낸다.

## 멈추고 묻는 때
- "새 후보"가 나왔을 때: docs에 없는 숫자가 필요하다. 레퍼런스 값과 시점을 보여 주고 값을 묻는다 (`docs/motion.md` 새 후보 표 참고).
- critic 판정에 `같은 곳 2회`가 붙었을 때: 더 고치지 않고 걸린 곳을 보여 주고 어떻게 할지 묻는다.
- BRIEF의 "무엇을"에 맞는 화면 · 부품이 `src/`에 없을 때: 새로 그리지 않고 묻는다.

## 보여 주는 방식
- 단계마다 결과(요약 · 이미지 · 영상)를 먼저 보여 주고, 판정은 한 줄로 쓴다.
- 기준 문서 내용은 옮겨 적지 않고 "motion.md 3장"처럼 가리킨다.
